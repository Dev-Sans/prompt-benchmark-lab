# Scoring Methods

The outputs generated by Gemini 3 were evaluated using a rubric consisting of four criteria:

1. Correctness
2. Format Compliance
3. Hallucination
4. Consistency

Each criterion was scored on a scale of 0–2, giving a maximum of **8 points per test case**. With eight test cases per prompt variation, the maximum score for each prompt was 64 points.

## 1. Evaluation Criteria

### A. Correctness

Evaluates whether the model assigns the complaint to the expected category.

| Score | Description                                                                          |
| ----: | ------------------------------------------------------------------------------------ |
|     2 | The predicted category matches the expected category.                                |
|     1 | The prediction is partially relevant but does not identify the main issue correctly. |
|     0 | The predicted category is incorrect or unrelated to the main issue.                  |

### B. Format Compliance

Evaluates whether the response follows the output-format requirements of the prompt.

| Score | Description                                                                                              |
| ----: | -------------------------------------------------------------------------------------------------------- |
|     2 | The response contains exactly one valid category name in the required format.                            |
|     1 | The correct category is present, but the response contains a minor formatting deviation or extra text.   |
|     0 | The response does not provide a valid category in an acceptable format, or provides multiple categories. |

### C. Hallucination

Evaluates whether the model introduces unsupported information into its response.

| Score | Description                                                                                        |
| ----: | -------------------------------------------------------------------------------------------------- |
|     2 | No invented facts or unsupported claims are present.                                               |
|     1 | A minor unsupported detail is included but does not affect the classification.                     |
|     0 | Significant invented information or unsupported assumptions affect the response or classification. |

### D. Consistency

Evaluates whether the model applies its classification approach consistently across related test cases.

| Score | Description                                                                                                      |
| ----: | ---------------------------------------------------------------------------------------------------------------- |
|     2 | The classifications are consistent with the expected approach across related cases.                              |
|     1 | A minor inconsistency is observed.                                                                               |
|     0 | Contradictory classifications are given for equivalent or closely related cases without a justified distinction. |

## 2. Total Score Calculation

The total score for each test case is calculated by adding the scores for all four criteria.

**Formula:**

`Total Score = Correctness + Format + Hallucination + Consistency`

The maximum score per test case is 8.

The total score for each prompt variation is the sum of its scores across all eight test cases.

**Formula:**

`Prompt Score = Sum of scores across all test cases`

The maximum possible prompt score is:

`8 test cases × 8 points = 64 points`

## 3. Score Percentage

To compare the overall performance of the prompt variations, the total rubric score is converted into a percentage.

**Formula:**

`Score Percentage = (Total Score / 64) × 100`

This percentage represents the proportion of available rubric points earned. It is **not the same as classification accuracy**.

## 4. Scoring Results

| Prompt Variation  | Total Score | Maximum Score | Score Percentage |
| ----------------- | ----------: | ------------: | ---------------: |
| Basic             |          54 |            64 |           84.38% |
| Few-Shot          |          64 |            64 |             100% |
| Instruction-Heavy |          62 |            64 |           96.88% |

## 5. Scoring Notes

- The expected categories defined in the test cases were used as the reference for correctness.
- The Basic prompt responses included a `Category:` prefix. These responses received 1 point for format compliance under the applied rubric.
- The Instruction-Heavy prompt received 0 points for correctness on TC05 because its prediction differed from the expected category.
- The Basic prompt received 0 points for correctness on TC08 for the same reason.
- The scoring criteria were applied to all three prompt variations to support comparison using a common rubric.

## 6. Limitations

Some criteria, especially consistency and hallucination, involve subjective judgment.

Consistency requires comparing outputs across related test cases. Since only eight test cases were used, the results may not generalize to other complaints or situations.

The rubric score provides a broader evaluation than accuracy alone, but it does not establish that one prompt variation will perform better on all customer complaint classification tasks.
